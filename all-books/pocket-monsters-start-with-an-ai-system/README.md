# Pokemon: Start with an AI System

Source: https://wtr-lab.com/en/novel/19293/pocket-monsters-start-with-an-ai-system

Downloaded existing English AI translations from WTR-LAB (the reader default). Text is preserved without editorial rewriting. Source and shared glossary mappings resolve WTR-LAB term markers into readable Pokémon names. Personal browser glossary overrides are not included.

- `pocket-monsters-start-with-an-ai-system.txt`: combined reading copy.
- `pocket-monsters-start-with-an-ai-system.html`: combined reading copy with linked contents.
- `pocket-monsters-start-with-an-ai-system_translated/`: individual HTML and text chapters.
- `pocket-monsters-start-with-an-ai-system_raw/`: source chapter metadata and unmodified content responses, without signed reader URLs or cookies.
- `book.json`, `chapters.json`, `glossaries.json`: metadata, ordered chapter manifest, and terminology source.
- `download-status.json`: final chapter counts, failures, and duplicate-body audit.

To resume or refresh locally, run the repository's `download-wtr.js` with the path to a WTR-LAB Netscape cookies export. Existing downloaded source chapters are reused. Locked or unavailable chapters are reported without unlocking or forced regeneration. If any chapters fail, combined filenames have a `-partial` suffix.
